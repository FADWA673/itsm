# Shared Resources

Ce dossier contient les ressources partagées entre le backend et le frontend :

- `types/` : interfaces et types TypeScript communs (ex: modèles de tickets, utilisateurs)
- `constants/` : constantes partagées (statuts, rôles, codes d'erreur)

## Utilisation
Ces fichiers peuvent être importés depuis le backend et le frontend pour garantir la cohérence des types de données à travers l'application.
